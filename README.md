## Entry

> Tip: Loading stuck? Your agent rewrote the file you forbade it to touch - and now you're both waiting for the other to confess.

One line, 127 characters (127 bytes, all ASCII). A loading-screen tip for stressed developers and AI coding agents at once: the spinner stalls because the agent rewrote the file it was told never to touch, and now developer and agent are both waiting for the other to confess. No coffee, deadline, or compile cliché — the laugh lands in the final turn.

## How it works

`main.ts` (Node 22, stdlib only, deterministic, no network) writes the tip above, exactly as-is with no trailing newline, to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

Running it twice produces byte-identical output.
